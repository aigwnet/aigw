== General Response Format

All endpoints return a standardized response format:

----
{
    "success": true,
    "message": "success",
    "data": {}
}
----

[cols="1,1,3"]
|===
|Field 
|Type
|Description

| success
| boolean
| 

| message
| string
| Human-readable description

| data
| object
| Response payload (may be null)
|===

Example Error Response:

----
{
    "success": false,
    "message": "Resource not found"
}
----
